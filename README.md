**Network Planner** — интерактивный браузерный САПР/планировщик для проектирования структурированных кабельных систем (**СКС / ЛВС**) и автоматического расчета сетевой инфраструктуры. 

Позволяет за считанные минуты начертить план здания, расставить рабочие места и сетевое оборудование, автоматически проложить оптимальные кабельные трассы с обходом стен и дверей, подобрать коммутаторы и выгрузить спецификацию материалов (BOM) в CSV.

Работает полностью на клиенте (**Zero Dependencies**): без сборщиков, внешних библиотек и серверного бэкенда — достаточно открыть `index.html` в любом современном браузере.

## 🚀 Ключевые возможности

### 📐 Инженерное чертёжное поле
- **Двухуровневая координатная сетка**: тонкие направляющие линии каждый 1 метр, контрастные акцентные линии каждые 5 метров.
- **Интерактивные линейки (Rulers)**: верхняя и левая измерительные шкалы с динамическими метками курсора и шагом в 1 метр.
- **Инструмент «Нарисовать комнату» (`[7]` / `R`)**: зажмите левую кнопку мыши на сетке и растяните помещение нужного размера с живым отображением габаритов ($W \times H$ м).
- **Магнитное прилипание (Smart Snapping)**: комнаты аккуратно пристыковываются друг к другу «стена-к-стене» без наложений и зазоров.
- **Информационные бейджи**: прямо на чертеже в каждой комнате отображаются её физические размеры и площадь (например, `6 × 5 м (30 м²)`).

### ⚡ Автоматическая топология и интеллектуальная трассировка
- **Иерархическая топология**:
  - Для комнат с $\ge 3$ устройствами автоматически выбирается оптимальное место и устанавливается **локальный коммутатор доступа** (с поддержкой PoE при наличии камер и Wi-Fi точек). К нему сходятся абонентские линии (`access`), а наружу выводится магистральный кабель (`uplink`).
  - Для небольших ком ($< 3$ устройств) кабели прокладываются напрямую к ядру/серверной по схеме **Home Run** без лишних промежуточных свитчей.
- **Оптимизированный алгоритм Дейкстры**:
  - Поиск кратчайших путей на базе **двоичной кучи (`MinHeap`)** со сложностью $O(E \log V)$ — трассировка десятков кабелей занимает миллисекунды.
- **Учёт физических препятствий и стен**:
  - Трассы строятся по коридорам и проходам. Пробитие глухой стены пенализируется высоким штрафом (`PENETRATION_PENALTY`), тогда как проход через двери (`doors`) и технологические отверстия (`penetrations`) выполняется беспрепятственно.
- **Двухуровневый магистральный роутинг и Fallback (v0.8.3)**:
  - Если чистый коридор перекрыт или изолирован, алгоритм мягко использует контролируемый транзит через смежные помещения (`allowRoomPenetration`), гарантируя 100% подключение всех узлов к ядру сети без сбоев.
  - При плотной расстановке оборудования коммутаторы безопасно размещаются в свободных внутренних ячейках комнат с аварийным манхэттенским соединением.

### 📊 Расчет спецификации материалов (BOM) и экспорт
- **Автоматический расчёт суммарного метража кабеля**:
  - Учёт горизонтальных участков по трассам;
  - Автоматическое добавление технологических вертикальных опусков к розеткам (**+1.5 м** на устройство);
  - Инженерный запас на укладку и разделку (**+10%**).
- **Подсчет количества строительных бухт**: расчет числа стандартных бухт кабеля «витая пара» по **305 м**.
- **Подбор активного оборудования**:
  - Анализ числа абонентов и PoE-потребителей;
  - Автоподбор моделей коммутаторов: 5-, 8-, 16- и 24-портовые коммутаторы (Standard / PoE).
- **Расходные материалы**: расчет требуемого количества коннекторов RJ-45 (с учетом портов патч-панелей и розеток).
- **Экспорт в CSV**: скачивание готовой сметы в один клик для Excel / 1С / Google Таблиц.

### 💾 Сохранение и загрузка проектов
- Полная выгрузка проекта в JSON-файл: геометрия комнат, оборудование, двери, отверстия, точка ввода провайдера и ручные стены.
- Мгновенное восстановление проекта из файла.

## ⌨️ Горячие клавиши (Hotkeys)

| Клавиша | Назначение | Описание |
|:---:|:---|:---|
| `1` / `V` | **Выбор** | Выделение и перетаскивание комнат и оборудования |
| `2` / `W` | **Стена** | Добавление дополнительной межкомнатной перегородки |
| `3` / `D` | **Дверь** | Установка дверного проема на стене |
| `4` / `P` | **Отверстие** | Технологическое отверстие / проходка для кабеля |
| `5` / `I` | **Точка ввода** | Установка точки ввода провайдера (ISP) или серверной |
| `6` / `E` | **Ластик** | Удаление дверей, отверстий или добавленных стен |
| `7` / `R` | **Нарисовать комнату** | Зажать ЛКМ на сетке и растянуть комнату нужного размера |
| `G` | **Трассировка** | Сгенерировать топологию кабельной сети |
| `Delete` / `Backspace` | **Удалить** | Удаление выбранной комнаты |
| `Esc` | **Сброс** | Снятие выделения или закрытие модальных окон |

## 🛠️ Установка и запуск

Проект не требует `node_modules`, компиляции или внешних серверов.

### Вариант 1: Быстрый запуск
Просто откройте файл `index.html` в браузере:
```bash
# Linux
xdg-open index.html

# macOS
open index.html

# Windows
start index.html
```

### Вариант 2: Локальный веб-сервер
Для комфортной работы и тестирования через `localhost`:
```bash
# Python 3
python3 -m http.server 8000

# или Node.js (npx)
npx serve .
```
Откройте в браузере `http://localhost:8000`.

## 🧩 Архитектура ядра (`js/app.js`)

1. **Дискретная модель сетки**:
   - Масштаб: $1 \text{ метр} = 28 \text{ пикселей}$.
   - Стены адресуются дискретными идентификаторами отрезков: `H:x:y` (горизонтальные) и `V:x:y` (вертикальные).
2. **Алгоритм поиска путей**:
   - Класс `MinHeap` реализует классическую двоичную кучу с $O(\log N)$ вставкой и извлечением минимума.
   - `findBackbonePath()` и `findPathRestricted()` используют модифицированный алгоритм Дейкстры с дифференцированными весами:
     - Обычный шаг по пустому коридору: `1`;
     - Шаг сквозь дверь/отверстие: `1`;
     - Шаг сквозь глухую стену: `+50` (штраф за пробитие);
     - Транзитный шаг сквозь внутреннее пространство чужой комнаты: `+12`.
3. **Локализация оборудования**:
   - `chooseBestSwitchLocation()` перебирает периметральные ячейки комнаты у шлюзов выхода, минимизируя суммарную длину абонентских кабелей и магистрального линка.

## 📜 История изменений (Changelog)

### v0.8.3
- **Исправление пропуска комнат**:
  - Устранена рассинхронизация `networkEntry.roomId` при ручном перемещении роутера провайдера. Точка ввода теперь строго привязывается к координатам на плане.
  - Разрешены шлюзы на смежных стенах между комнатами: двери больше не отфильтровываются при соприкосновении с соседними помещениями.
  - Реализован двухуровневый магистральный роутинг с автоматическим транзитным fallback через смежные комнаты при изоляции коридора.
  - Добавлен внутрикомнатный прямой аварийный роутинг (`buildDirectRoomPath`).

### v0.8.2
- Добавлен интерактивный инструмент рисования комнат мышью (`[7] / R`).
- Добавлены измерительные линейки (Rulers) с динамическими индикаторами курсора.
- Реализовано умное магнитное прилипание комнат (Smart Snapping).
- Внедрен калькулятор спецификации оборудования (BOM) с экспортом в CSV.
- Оптимизирован алгоритм Дейкстры переводом на двоичную кучу `MinHeap`.
